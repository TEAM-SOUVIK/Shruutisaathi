# ShrutiSaathi v1.0 Play Store listing draft

## App name

ShrutiSaathi v1.0

## Short description

Private live captions, conversation gist, and reply drafting for accessible conversations.

## Full description

ShrutiSaathi is a local-first conversation support app designed to help users follow spoken discussions, review labelled transcripts, understand the key gist, and prepare a clear response.

Core features:

- Live caption capture through the device microphone.
- Speaker-aware transcript organization with predefined speaker labels and experimental local speaker separation.
- Private AI Pack support for on-device conversation gist generation and reply drafting.
- Transcript correction controls so users can review and fix captured captions.
- User-controlled reply drafting: type short intent, review the generated draft, then decide whether to use it.
- Session reset and stop controls for clearing local history.

Privacy-first design:

- Conversation transcripts are stored in app-private storage.
- Transcripts are excluded from Android cloud backup and device transfer backup rules.
- The Private AI Pack runs locally on the device after one-time installation.
- Network access is used for the optional one-time AI Pack download.

Important note:

ShrutiSaathi is a research prototype and accessibility-support application. It is not a medical device, hearing aid, emergency alert system, legal transcription system, or certified assistive technology product. Always review captions, gists, and generated replies before relying on them.
